People

One list of admins and staff for every tool. The Time-Off Log fills its Admin field from the admins here, and Address Catcher uses the employee IDs to name who made a correction. Every tool on this site shares the list saved in this browser. With the repo set up in Settings below, this page loads the list from the repo and saves your changes back to it.

Settings

Paste a fine-grained GitHub token with Contents read and write on your private repo, then say where the People file is. Everything here is stored only in this browser. The token is never shown again.

The People list in this browser cannot be read. It was saved by a newer version of this page, or it is damaged. Nothing is shown and nothing is saved over it. The other tools use their built-in lists until it is fixed. Open the newest version of this page, or replace it with a backup. Replacing first saves a copy of the unreadable text to your Downloads, so nothing is lost.
